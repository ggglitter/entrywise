# Design record

## Context and authority
New application in a new project folder; no existing framework.
The participant delegated creation of competition works.

## Alternatives
Calendar: emphasizes time but hides exclusion reasons.
Cards: approachable but poor for comparing many similar entries.
Queue plus evidence sheet: compares deadlines and inspects one rule trace.
Selected the third as an agent decision, not a fabricated user preference.

## DNA
Independent creators. Precise, calm and editorial. Moderate density.
Paper and ink; orange means attention. Every status also uses text.
Sources attach to their decisions rather than a distant bibliography.

## Acceptance targets
Desktop and narrow layouts, long names, empty search, receipt error, save/reload.
Actual runtime screenshots required. An unbranded view must retain the task.
No comparator product exists inside this scoped project.

## Current result
Scoped visual review completed on actual desktop (1280 by 720) and narrow
(390 by 844) browser states. The narrow viewport has no horizontal overflow;
the age label was shortened after inspection. The queue, empty state and receipt
error were exercised. Runtime evidence and limitations: qa-results.json and
demo/stills. Brand-removal diagnostic was not performed. This is not a claim of
complete accessibility or all-device acceptance.
