# Entrywise scope

## Basis
The participant asked to collect rewarded competitions, exclude mandatory
attendance, then enter the free ones and have the assistant create permitted
works. Product details below are agent proposals, not learner interview answers.

## The Unique Kernel
Show the exact failed or unknown requirement before a creator spends time making
a work. A saved opportunity, registration and submission are different things.

## The Core Loop
Set country, age band, student status and creation method. Inspect a sourced
opportunity, read checks and save an entry plan. After a real platform action,
record its receipt, reload and export the local record.

## What Working Looks Like
A non-student adult in China must not pass a student-only competition.
Unknown upper age limits and memberships remain unknown.
A registration receipt must never increment the submission count.

## The POC Boundary
One static application, 23 source-linked opportunities, local persistence,
transparent rules and JSON export. No paid API or automatic applications.
